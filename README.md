## Enable GitHub Pages

1. Open **Settings → Pages** on this repository  
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**  
3. Branch: `main` · Folder: `/docs`  
4. Save — the site will be at `https://0xcloud-io.github.io/.github/`

## Brand assets

Logos and hero art live in [`docs/assets/`](docs/assets/), copied from the product site (`0xcloud.io` / crypto-vps-frontend).

## CTAs

All conversion links point to [0xcloud.io](https://0xcloud.io) with UTM params (`utm_source=github`) so traffic from GitHub is measurable.
